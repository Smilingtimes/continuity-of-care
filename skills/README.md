# Local Skills Library

Store full skill packages here only when this is their intended source or installation location. Each should contain `SKILL.md` and have a verified entry in `../SKILL-REGISTRY.md`.

A file here is not automatically available in ChatGPT, Codex, Claude Code, Cursor, or another platform. Verify installation and invocation separately.

Use `../SKILL-REGISTRY.md` for brief discovery and your detailed skill catalog (if you keep one) for full records. Download a full skill package only when a current project has selected it and its source and security implications have been reviewed.

Do not copy all cataloged skills into this folder. Installation locations and discovery behavior differ by platform.
