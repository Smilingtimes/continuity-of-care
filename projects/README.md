# Projects

One folder per project. Each project gets:

- `PROJECT.md` — copied from `templates/PROJECT-TEMPLATE.md`; the verified
  source of truth for status, architecture, decisions, and open questions.
- `SKILLS.md` — copied from `templates/PROJECT-SKILLS.md`; which skills apply
  at the current stage, and when to reassess.

An AI collaborator reads these before touching a project, so "continue project
X" works without a verbal briefing.
